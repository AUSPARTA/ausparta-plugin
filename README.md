# Ausparta

Cursor plugin for the Ausparta training app. It connects to `https://app.ausparta.com/api/mcp`. There is no shared token in this repo. Each person signs in on `https://app.ausparta.com/connect` and approves access to their own account.

## Install in Cursor

Submit or install this repository from the [Cursor Marketplace](https://cursor.com/marketplace). After it is listed, open **Customize → Plugins & MCPs**, find Ausparta, and click **Add**.

To try it before it is listed, clone this repo into `~/.cursor/plugins/local/ausparta` and reload Cursor. It then appears under Plugins & MCPs.

## What it can do

Once approved, the agent can read and update that person's training profile, program week, and workout history.
